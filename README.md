
# Diixo
## Dialogue Intelligence Infrastructure for eXperimentation and Optimization

**Diixo is a framework for building, training, and evaluating intelligent conversational models.**

## Diixo:
Diixo is an open-source framework for preparing dialogue datasets, training conversational language models, and evaluating their behavior across multi-turn tasks.

* Dialogue Intelligence — основное направление;
* Infrastructure — датасеты, модели, тренеры, конфигурации;
* eXperimentation — проведение и сравнение экспериментов;
* Optimization — pretraining, SFT и настройка моделей.

```text
Diixo
├── Datasets
├── Dialogue Tasks
├── Models
├── Trainers
├── Agents
├── Evaluators
└── Experiments
```

Diixo может обучать:
* генеративные dialogue-модели;
* question-answering модели;
* instruction-following модели;
* task-oriented assistants;
* multi-turn модели с историей;
* эмоциональные и персонализированные модели;
* multi-agent системы.
